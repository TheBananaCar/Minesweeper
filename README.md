# Minesweeper in Terminal
- 3 difficulty levels:
  1)  Easy: 10x10 with 10 bombs
  2)  Medium: 16x16 with 40 bombs
  3)  Hard: 30x16 with 99 bombs

- Color for player's current space, revealed spaces, and spaces with a flag/bomb.
- Program reads in arrow keys, d, f, and enter.
- Arrow keys to move.
- D for clicking in game.
- Enter for clicking in menu and game.
- F for placing flag.
